# 🛍️ IBS Frontend - Каталог товаров

## 📝 Описание проекта

Это проект **Single Page Application (SPA)** на React + Redux, представляющий собой интерактивный каталог товаров с возможностью просмотра детальной информации о продуктах. Приложение реализует современные подходы к разработке фронтенда с использованием актуальных технологий и библиотек.


![Catalog Page](/src/img/Catalog_Page.png)
![Catalog Item](/src/img/Catalog_Item.png)
## ✨ Основные возможности

- 🔍 **Поиск товаров** - быстрый поиск по названию с debounce-оптимизацией
- 📱 **Адаптивный дизайн** - корректное отображение на различных устройствах
- ❤️ **Избранное** - добавление/удаление товаров в избранное
- 🔄 **Состояние загрузки** - индикаторы загрузки и обработка ошибок
- 🎨 **Современный UI** - использование Material-UI компонентов
- 📊 **Управление состоянием** - Redux Toolkit для централизованного состояния

## 🏗️ Структура проекта

```
src/
├── api/                    # API слой
│   ├── api.ts             # Основные API функции
│   ├── apiClient.ts       # HTTP клиент (Axios)
│   └── apiConfig.ts       # Конфигурация API
├── components/            # React компоненты
│   ├── catalog/           # Компонент каталога
│   ├── catalogCard/       # Карточка товара в каталоге
│   ├── header/            # Шапка с поиском
│   ├── modalError/        # Модальное окно ошибок
│   └── product/           # Страница товара
├── constants/             # Константы приложения
├── enums/                 # Перечисления
├── helpers/               # Вспомогательные функции
├── layouts/               # Макеты страниц
├── pages/                 # Страницы приложения
├── routes/                # Маршрутизация
├── slices/                # Redux слайсы
│   ├── catalogSlice/      # Состояние каталога
│   ├── productSlice/      # Состояние товара
│   ├── favoriteSlice/     # Состояние избранного
│   ├── quantitySlice/     # Состояние количества
│   └── errorSlice/        # Состояние ошибок
├── store.ts               # Конфигурация Redux store
├── styles/                # Глобальные стили
└── utils/                 # Утилиты и хуки
```

## 🛠️ Технологии и библиотеки

### Основные технологии

- **React 18.3.1** - библиотека для создания пользовательских интерфейсов
- **TypeScript 5.7.2** - типизированный JavaScript
- **Redux Toolkit 2.4.0** - современный подход к управлению состоянием
- **React Router DOM 7.0.1** - маршрутизация в React приложениях

### UI библиотеки

- **Material-UI 6.1.10** - компоненты интерфейса
- **Styled Components 6.1.13** - CSS-in-JS решение
- **Emotion** - библиотека для стилизации

### HTTP клиент

- **Axios 1.7.7** - HTTP клиент для API запросов

### Инструменты разработки

- **Webpack 5.96.1** - сборщик модулей
- **Babel** - транспайлер JavaScript
- **Sass** - препроцессор CSS
- **ESLint** - линтер для JavaScript/TypeScript


## 🎯 Особенности реализации

- **Debounce поиска** - оптимизация поисковых запросов
- **Error Boundary** - обработка ошибок React компонентов
- **Lazy Loading** - ленивая загрузка изображений
- **Responsive Design** - адаптивная верстка
- **TypeScript** - строгая типизация для повышения надежности
- **Redux Toolkit** - современный подход к Redux с меньшим количеством boilerplate кода
